What each block does

A system on chip is a set of blocks joined by buses. Masters start transfers; slaves answer them. AXI is the fast bus: it has separate read and write channels and supports bursts. APB is the simple bus for slow register blocks. The bridge turns one AXI transfer into one APB transfer.

Address map

Every slave owns a window of addresses. The interconnect decoder looks at the address and picks one slave. An address that no slave owns gets an error response: DECERR from the interconnect, or SLVERR from the bridge when the address is inside the APB window but no peripheral is there.
