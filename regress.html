How to read it

A failing test is good news

Here every row has a bug in it, so a red “FAIL” means the test did its job. A green cell is a catch.

Rows that escape are holes

A bug that no test catches is a hole in your verification. Fix it with a new test, a new check, or a missing testbench part.

Some tests catch a lot

Random and the address map test catch many bugs cheaply. Narrow bugs, like a watchdog that accepts any kick value, need a test written for that feature.

Checks matter as much as stimulus

Switch to “No assertions” and run again: protocol bugs such as a burst crossing 4 KB escape even though the same transfers ran.
