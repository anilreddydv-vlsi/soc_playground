Share link

The whole design fits in a link. Anyone who opens it gets your SoC on their Build page. Nothing is uploaded: the design travels inside the link itself.








Register spec


Every register in your SoC, with its full address. Print it or save it as PDF from the print dialog, or download it as a spreadsheet file.











RTL and testbench


Real SystemVerilog for the APB side of your SoC: the address package, both decoders, one register block per peripheral (with wait states, write-1-to-clear, the timer, watchdog and interrupt behaviour), and the APB subsystem that ties them together. The testbench reads back the reset values and write patterns of the registers it can check directly, and prints TEST PASSED. The AXI memories and interconnect stay in the browser model.


Run it with any SystemVerilog simulator, for example: verilator --binary --timing --top-module tb soc_rtl.sv soc_tb.sv













UVM register model


A uvm_reg_block per peripheral, mapped at its base address, plus a test that runs the built-in reset sequence. Write-only registers have no reset to read, and registers that hardware changes (counters, interrupt status, GPIO inputs) are marked volatile so the sequence skips them. Connect the map to your APB agent with an adapter and it checks every reset value through the bus.
